# 🚀 DRIOL // PULSE — Enterprise Telemetry Matrix v2.4

**DRIOL // PULSE** is a next-generation real-time hardware telemetry and predictive analytics dashboard engineered by **Daniel Olusodo (DRIOL)**. 

Designed for high-frequency IoT data streams, smart grid monitoring, and industrial hardware telemetry over WebSockets/MQTT.

---

## ✨ Features

- **Live WebSocket Data Stream:** High-frequency chart rendering without frame drops.
- **Predictive AI Anomaly Engine:** Real-time forecasting of hardware thermal throttling & component failure trajectories.
- **Interactive "What-If" Hardware Sandbox:** Operator simulation controls to stress-test thermal loads and target voltages dynamically.
- **OLED Dark-Mode Spatial Design:** Built with Tailwind CSS, spatial glassmorphism layers, and custom typography.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 14+ (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Charts:** Recharts
- **Icons:** Lucide React

---

## ⚡ Getting Started

1. **Extract Zip File & Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Development Server:**
   ```bash
   npm run dev
   ```

3. **Open Browser:**
   Navigate to `http://localhost:3000` to view live telemetry.
